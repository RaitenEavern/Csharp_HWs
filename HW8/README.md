## Задача 1.
### а)
public string Name { get; set; } попадёт, так как публичное и является свойством.
public int Score { get; set; } аналогично первому.
private int secretCode = 42; не пройдёт, так как является private.
public bool IsAlive; не пройдёт, так как является полем, а не свойством.

### б) 
Чтобы оно попало в JSON, нужно добавить атрибут [JsonInclude] над строкой, которую нам надо добавить.
```csharp
[JsonInclude]
private int secretCode = 42;
```
Тогда оно добавится, но в начале файла нужно добавить using System.Text.Json.Serialization;, так как по умолчанию его нет.

### в)
Оно не попадает, так как является полем, а не свойством.
Первый способ: аналогично тому, что мы делали в б), добавить нужный атрибут.
Второй способ: сделать поле свойством public bool IsAlive { get; set; }.
А вообще есть ещё и третий: в настройках сериализации включить IncludeFields = true.

## Задача 2.
### а) 
```csharp
public class Game
{
    public string Title {get; set;}
    public int Year {get; set;}
    public double Rating {get; set;}
    public string[] Genres {get; set;}
    public bool IsMultiplayer {get; set;}
}
```
### б)
Сериализатор по умолчанию различает регистр букв, поэтому ключ title не совпадает со свойством Title.
Ключ пропускается, и Title остаётся null.
Решение: включить в настройках PropertyNameCaseInsensitive = true и передать их в Deserialize.

### в)
Да, это валидный JSON: это массив, а в JSON элементы массива могут быть разных типов.
Его можно десериализовать в object[], потому что в object помещается значение любого типа.
